
CONTRIBUTING TO ACE
 
This is a public, general-purpose simulation tool. All contributions
become public.
 
ALLOWED:
  - General-purpose code useful for any rocket.
  - Your own work, based only on public information.
 
NOT ALLOWED:
  - Code built for a specific organization's vehicle.
  - Any organization's vehicle data, configs, or tuning.
  - Sponsor, export-controlled, or otherwise restricted information.
 
If you are unsure, do not submit it.
 
All contributions go through pull requests reviewed by the maintainer.
Sign off every commit (git commit -s) to certify you followed these rules.
